🛒 QuickMart – Online Grocery Delivery App
QuickMart is a full-featured grocery e-commerce web application that lets users browse products, manage a shopping cart, and check out — all with a fast, modern shopping experience.
✨ Features

User Authentication – Secure login/signup system with email and password
Category-Based Shopping – Browse groceries across categories like Vegetables, Fruits, Dairy, Bakery, Pantry, Household, Beauty, and Beverages
Deals of the Day – Highlighted daily discounts on popular products
Shopping Cart – Add, update quantity, or remove items with real-time price calculation
Promo Codes – Apply discount codes at checkout for instant savings
Order Summary – Live breakdown of subtotal, shipping, discounts, and total
Responsive UI – Clean, intuitive interface built for a smooth shopping flow

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript, React
Build Tool: Vite
Backend/API: JSON Server (mock REST API for products, cart, and user data)

🚀 Getting Started
bash# Clone the repository
git clone <your-repo-url>

# Install dependencies
npm install

# Start the JSON server (mock backend)
npx json-server --watch db.json --port 5000

# Start the development server
npm run dev
The app will be available at http://localhost:5173
